### 🛒 Feira Digital de Trocas

Aplicação web para cadastro e gerenciamento de itens destinados a **troca, doação ou venda**.

**Tecnologias:**

* HTML
* CSS
* JavaScript
* LocalStorage

**Principais recursos:**

* Cadastro de produtos
* Validação de formulário
* Pesquisa de itens
* Controle de disponibilidade
* Persistência dos dados com LocalStorage
* Interface responsiva

Aplicação de gerenciamento de tarefas desenvolvida para praticar **JavaScript e manipulação do DOM**.

* Marcar tarefas como concluídas
* Remover tarefas
* Validação de tarefas duplicadas
* Salvamento automático com LocalStorage
